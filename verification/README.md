## 局限与失败记录
- 测试浏览器禁止 file:// 导航，未绕过。单文件通过 HTTP 执行验证且源码无外部依赖，但字面意义上的双击本地文件未通过 UI 工具实测。若浏览器禁用 file 页 localStorage，游戏会明确显示存档失败；可用本地服务器版本。
- Blob 下载未产生工具可观察下载事件。已增加可见 JSON/粘贴导入途径并实测成功；文件下载属于可选兼容路径。
- 没有人工趣味评估、长期平衡评审或专业配乐。声音由 WebAudio 本地合成，默认关闭环境低鸣。
- 截图检查和实际控件自动化不等于人类玩家觉得好玩。没有联机、AI 自由对话或商业原作内容体量。
